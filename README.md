# E-commerce: Productos de Limpieza 🧼✨

Este proyecto es una plataforma de comercio electrónico diseñada para la visualización, selección y simulación de compra de productos de limpieza para el hogar e institucionales. El objetivo principal es ofrecer una experiencia de usuario fluida, rápida y adaptada a cualquier dispositivo.

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript
* **Diseño y Estilos:** Responsive Design (Adaptable a celulares y computadoras)
* **Control de Versiones:** GitHub

## 💻 Características Principales

* **Catálogo de Productos:** Visualización organizada de artículos de limpieza con precios y descripciones.
* **Carrito de Compras:** Funcionalidad dinámica para agregar, eliminar y calcular el total de los productos en tiempo real.
* **Interfaz Intuitiva:** Navegación limpia y atractiva pensada para el usuario final.
